# Contributing

1. Read [CLAUDE.md](CLAUDE.md). Skills follow each library's published docs.
2. Run `node scripts/check.mjs --links`, `node --test` and `claude plugin validate .`.
3. Use [Conventional Commits](https://www.conventionalcommits.org/), for example `docs(helios): explain stencil setup`.

You own every commit, including code an AI wrote. Do not add AI-attribution trailers.

Report a bug in a library to that library's repository.
